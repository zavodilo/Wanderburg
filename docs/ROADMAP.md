# ROADMAP Wanderburg — модели, победы, проверки

Публичный план игры поверх [ArcEngine/PlayArcEngine](https://github.com/zavodilo/PlayArcEngine).
Стратегия самого набора — в `ROADMAP.md` набора; здесь — только Wanderburg.
Статус задач: `[ ]` — не начато, `[~]` — в работе, `[x]` — готово и проверено.
Любая модель со стороны — только **CC0 / CC-BY с атрибуцией в NOTICE**; интеграция — через
запекание (`tools/make-pack-geo.mjs`) или штатный путь набора (`Location3D.addObject` +
`def.fallback`), процедурная геометрия остаётся фолбэком (инвариант набора).
