# ROADMAP Wanderburg — модели, победы, проверки

Публичный план игры поверх [ArcEngine/PlayArcEngine](https://github.com/zavodilo/PlayArcEngine).
Стратегия самого набора — в `ROADMAP.md` набора; здесь — только Wanderburg.
Статус задач: `[ ]` — не начато, `[~]` — в работе, `[x]` — готово и проверено.
Любая модель со стороны — только **CC0 / CC-BY с атрибуцией в NOTICE**; интеграция — через
запекание (`tools/make-pack-geo.mjs`) или штатный путь набора (`Location3D.addObject` +
`def.fallback`), процедурная геометрия остаётся фолбэком (инвариант набора).

---

## A. Победа автопилота (verify/winrun.mjs)

Сегодня: 0 побед при честной игре; лучший забег — регион 0 зачищен, варден убит, выход в регион 1
(seed 51756, 23 убийства, tier 5). Поражения: ранние смерти 16–26 s (драка до тайра 3) и бой с
варденом/Венцом (30–70 s после bossSpawn).

- [x] A-1 Детерминированный harness: сид, лог причин поражения, таблица забегов.
- [x] A-2 Фарм-фаза: не ввязываться до tier 3 + 4 модулей, есть вне карманов врага.
- [x] A-3 Уход от снарядов по перпендикуляру (tti < 0.9 s).
- [x] A-4 Орбита на дальности своей дальней пушки в дуэлях.
- [~] A-5 Политика боя с варденом: орбита [0.75·reach, 0.95·reach], отход при hp < caution
      (caution растёт с регионом), сайдстеп charge-телеграфа, фокус только на боссе.
      Диагностика смертей (verify/winrun.mjs печатает tally урона): регион 0–1 убивают
      `bullet/bolt`-залпы в радиусе врага и `lance/spark` в упор, регион 2+ — суммарный DPS.
      Лучший забег: регион 2, два вардена, 49–60 убийств. Критерий: 3+ победных боя с варденом
      из 10 сидов. Отклонено как тупик: таймерный hit-and-run (столлы), таран рыцарей у крепостей
      (ловушки), patch-окно на входе в регион (столлы).
- [ ] A-6 Политика Железного Венца: crown призывает подкрепления и enrage — держать дистанцию
      по telegraph, жечь призванных осами/мортирами, не танковать. Критерий: 1+ `won=true`.
- [ ] A-7 Чертежи: скоринг с учётом синергий капитана и корпуса (сейчас — жадная оценка карты).
- [ ] A-8 Прогон 20 сидов × 4 региона в CI-подобном режиме (ночной прогон, отчёт в verify/).
